01 — The core change

Identity comes from the install path, not the file name

v1 compared executable names against a list of 25 games. The list could not grow quickly enough. It also made errors it could not detect: it mapped javaw.exe to Minecraft, so every Java application on the machine reported as Minecraft.

v2 asks the launcher. Steam records that appid 730 is in …/steamapps/common/Counter-Strike Global Offensive. Any process below that directory is that game. This includes every shipping binary, launcher and helper, with no entry per game. Name ambiguity becomes impossible on that rung.

The first match wins. The curated table is checked before the library scan because it holds the stable game_id that telemetry and stored statistics use as their key. To resolve CS2 as steam-730 would orphan them.

02 — Where this sits

Four specs, one pipeline, one direction

Specs 16 to 19 describe one pipeline. They were easy to confuse. Each one now answers a single question, and data moves in one direction. The rule is short: if it renders, it belongs to spec 19. If it detects or records, it belongs to 16, 17 or 18.

Nothing in 17 or 18 knows that a feed card exists. Nothing in 19 knows how a game was detected. That boundary is the reason this work changed no surfaces.

Three plan decisions that the measurements reversed

Where the catalogue lives

I said that 350k titles cannot fit the install budget. This is true of the raw dump and false of the derived catalogue, which packs to 701 KB. Both artifacts now ship in the installer. Identity resolves offline, and there is no delivery path to operate.

Launcher priority

Steam is 77% of the catalogue, so I put the other launchers last. Breadth is not play: 13 of the 50 most-played games cannot be found by a Steam scan. The curated head came first instead.

Crowd mappings

Removed, not delayed. A game with no name already gets a session, a shared id, a name and an icon. A submission table with moderation bought only the display name. A local log plus hand curation gives the same result.

Test, validate, release

  1. Run the full gate

    ./scripts/check-full.sh has not run since the catalogue consolidation. That change touched 18 files and removed a module. The full gate adds the C++ ctest and Go lanes that check.sh does not run. Do this first.

  2. Run the client and watch one real session

    Start a game. Confirm that [game-sensor] game started: gives the correct name. Then quit the game and confirm that the duration agrees with the clock. Nothing has driven the full path from end to end yet.

    Roblox, WoW, Diablo IV, PUBG, War Thunder and the HoYoPlay games come from knowledge, not observation. Each one fails safely, because the game does not resolve. Each failure is therefore silent until a person looks.

    The install was 102 MB before this work, against a target of 100 MB. This work adds 701 KB and removes the embedded icon set. The 86 MB mello.exe is a different problem. A background task is open for it.

05 — Worth knowing

Things the diff will not show you

Tests against real installs found bugs that unit tests could not. A scan of your Steam library found every game two times, because libraryfolders.vdf writes the install root with a different spelling than the registry. A probe of your Hearthstone install found Hearthstone Beta Launcher.exe tracked as its own game, because the engine-marker test looks at the directory. Both are corrected. Continue to use cargo test -p mello-core --lib resolution_report -- --ignored --nocapture.

  • Two silent bugs are now corrected. javaw.exe mapped every Java application to Minecraft. Feed cards showed an empty badge for any game outside the bundled 25, which after this work would be almost all of them.
  • I moved away from the plan one time, on purpose. The plan said the classifier must gate the prompt but never the tracking. That rule would have written “played Notepad for 4 hours” to the crew feed. The classifier now gates tracking also.
  • The stability of game_id is load-bearing. IGDB calls Minecraft minecraft-java-edition, and divides StarCraft II into three entries. The telemetry adapters and all stored statistics use the old ids as their key, so the curated table holds them.
  • Spec 19 keeps the open question: one rollup card, or one card for each session. The data supports both.
  • The macOS code is written but not run. Bundle icon extraction and launcher paths are complete. No part of it has executed on a Mac.
